SafraLink — protótipo front-end

Estrutura:
- index.html: entrada/login
- cadastro.html: cadastro de usuário comum
- tornar-vendedor.html: cadastro complementar para virar vendedor/produtor
- inicio.html: painel inicial
- produtos.html: produtos disponíveis e busca
- colheitas.html: previsões de colheita
- pedidos.html: solicitações e negociações
- transporte.html: logística e transporte
- sobras.html: controle de sobras/desperdícios
- perfil.html: dados do usuário
- css/style.css: estilos do projeto
- js/app.js: navegação, dados de exemplo e interações

É um protótipo sem backend. Os dados são mantidos no localStorage do navegador.
